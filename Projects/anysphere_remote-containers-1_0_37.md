## 🧭 Overview & Mission
This extension enables you to use Docker containers as your development environment. It provides a consistent, isolated workspace with all the tools and dependencies you need. - Runs your development environment inside a Docker container - Mounts your workspace files into the container - Installs and runs extensions inside the container - Provides seamless integration with Cursor as if everything were running locally You can use Docker in several ways: - Local Docker installation - Remote Docker
