The Pyrefly extension uses Pyrefly to provide language server features for Python in VS Code. Please see [pyrefly.org](https://pyrefly.org/) for more information. The Pyrefly extension: - Adds inline type errors matching the Pyrefly command-line to your editor. By default, a project without a Pyrefly configuration uses the [`basic`](https://pyrefly.org/en/docs/configuration/#preset-basic) preset or auto-migrated settings from a nearby `mypy.ini` / `pyrightconfig.json`.
